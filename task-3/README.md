# Анализаторы кода

## Выбранный проект

[Tinylog](https://github.com/tinylog-org/tinylog) - легковесная библиотека логирования для Java‑приложений.

В [документации](https://tinylog.org/) авторы заявляют о преимуществах библиотеки:

* Отсутствие шаблонного кода засчет наличия статического класса

* Множество вариантов вывода: tinylog поддерживает множество средств записи для вывода логов. Логи могут быть записаны на консоль, в файлы JSON, в таблицы базы данных и так далее

* Совместимость с Java 6+, API для java и другие языки jvm, специальное api для kotlin и scala

* Легковестность - 195 KB и всего два jar файла

* Скорость вывода логов - вывод сотен тысяч логов в секунду

## Структура выполнения

В каждом файле описан результат анализа конкрентной утилиты, в этом же файле содержится сравнение результатов

## Сравнение анализаторов кода: CKJM и SonarQube

### Разница подходов

Несмотря на то, что оба инструмента направлены на оценку качества программного обеспечения, они используют различные подходы, метрики и уровни анализа, что приводит к заметным различиям в результатах.

SonarQube анализирует весь исходных код, CKJM анализирует байт-код (.class-files). CKJM направлен на подсчет метрик качества кода и архитектуры системы, SonarQube сосредоточен скорее на оценке практических характеристик кода с помощью CK-метрик, полезных с точки зрения разработки и сопровождения (комментарии, надежность, безопасность, поддерживаемость, сложность, дублирование и так далее.)

### Сопоставление основных метрик

Некоторыен метрики могут расходиться, в том числе потому что SonarQube (SQ в таблице) оценивает исходный код целиком, включая код тестов и бенчмарков.

### Корреляционный анализ

В обоих анализаторах выявлены схожие связи между метриками:

* Сложность кода (WMC / Cyclomatic) напрямую зависит от количества методов (NPM / Methods) – коэффициенты корреляции 0.993 (CKJM) и 1.000 (SonarQube).

* Рост сложности ведёт к увеличению дефектов – в CKJM корреляция WMC $\leftrightarrow$ RFC = 0.854, в SonarQube Cyclomatic $\leftrightarrow$ Bugs = 0.853 (практически идентично).
